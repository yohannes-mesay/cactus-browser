Cactus Browser

A native daily driver for Linux: Rust and libadwaita around WebKitGTK. Blocking and HTTPS defaults are on from the first launch. Nothing phones home.

Telemetry stays at zero. Counters live in your SQLite file, not a vendor dashboard.

Config under XDG paths. Private windows use a separate network session.

Version 1.2 adds a live privacy dashboard and session stats on the new tab page—still aimed at GNOME users who want sane defaults without another Chromium fork.

Request policy

EasyList and EasyPrivacy through Brave’s adblock engine, plus cosmetic filtering. HTTPS-First, DNT, and Global Privacy Control. Per-site allowlists when you trust a publisher.

Native shell

Multi-window tabs, bookmark bar, session restore, find-in-page, zoom, and shortcuts that match habit.

On disk

~/.config/cactus for prefs, ~/.local/share/cactus for data. Auditable, portable, yours.

Build from source

Install dev packages for GTK4, libadwaita, WebKitGTK 6, and SQLite. Use rustup stable, then compile at the repo root.

  • Flatpak manifest in flatpak/org.cactus.Browser.yml
  • source scripts/env.sh when headers live in .deps/
  • Internal URIs: cactus://settings, history, bookmarks
shell
# Debian / Ubuntu (example)
sudo apt install build-essential pkg-config \
  libgtk-4-dev libadwaita-1-dev \
  libwebkitgtk-6.0-dev libsqlite3-dev

cargo build --release
./target/release/cactus
